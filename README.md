# Flutter Weather UI

A clean Flutter weather experience featuring current conditions, hourly forecasts and responsive forecast cards.

## Highlights

- Current weather overview
- Hourly forecast timeline
- Temperature, wind and condition presentation
- Responsive card-based interface
- Reusable Flutter widgets and Material theming

## Tech stack

Flutter, Dart and Material Design.

## Run locally

```bash
flutter pub get
flutter run
```

## Project status

Portfolio UI project demonstrating responsive Flutter layouts and reusable weather components.
